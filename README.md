# Salman Al-Juhani — Sales Intelligence Platform

A portfolio project for an Information Systems student.

## Stack
SQL Server + Power BI + Excel/CSV

## Files
- fact_sales.csv — transaction fact table
- dim_product.csv — product dimension
- dim_branch.csv — branch dimension
- dim_customer.csv — customer dimension
- 01_database_and_queries.sql — database schema + KPI queries
- 02_powerbi_blueprint.md — dashboard layout + DAX
- 03_business_case.md — business requirements and CV-ready description

## How to use
1. Import the CSV files into SQL Server.
2. Run 01_database_and_queries.sql after creating/loading the tables.
3. Connect Power BI to SQL Server.
4. Build the three dashboard pages using the blueprint.
5. Take screenshots of the finished dashboard and publish the project on LinkedIn/GitHub.

Important: the data is synthetic and created for portfolio/learning purposes.
