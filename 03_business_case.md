# Business Case

## Problem
A multi-branch retail company has sales data but lacks a single management view of revenue, profit, branch performance and product performance.

## Objective
Build a Sales Intelligence Platform that converts transactional data into actionable management insights.

## Stakeholders
- CEO / General Manager
- Sales Manager
- Branch Managers
- Finance Team
- Business Analyst

## Key Questions
1. What is total revenue and profit?
2. Which branches generate the highest revenue and profit?
3. Which products are most profitable?
4. Which sales channel performs best?
5. Are discounts reducing margins?
6. How does performance change month over month?

## Deliverables
- Relational SQL database
- Clean dimensional model
- SQL KPI queries
- Power BI dashboard
- Executive insights
- Portfolio documentation

## CV bullet
Built an end-to-end Sales Intelligence Platform using SQL and Power BI, including a relational data model, KPI queries, interactive dashboards, branch/product/channel analysis, and management recommendations.
